Starter kit

Downloads the competition images and labels from the 3LC content network to the machine running the compute service, then verifies every file against the published manifest.

Saves to on the service machine. An interrupted download keeps its finished parts and resumes.

Training parameters

        

          

            
            
            
Passes over the training data. The pretrained start converges
              fast: a plain run reaches about 0.70 val mAP50 by epoch 10. 10 to 50 is the
              productive range; use Patience to stop early. Range 1 to 300.

            

            

          

          

            
            
            
Images per training step. Raise it until GPU memory runs out;
              lower it on CUDA out-of-memory. 16 fits an 8 GB card at 640px. Range 1 to 128.

            

          

          

            
            
            
Initial learning rate. Higher learns faster but can diverge;
              0.01 is a solid start with SGD/auto. Range 0.0001 to 0.1.

            

          

          

            
            
            
Final learning rate as a fraction of lr0. The schedule decays
              toward lr0 × lrf; lower means stronger late decay. Range 0.01 to 1.0.

            

          

          

            
            

              
              
            

            
Auto picks SGD or AdamW from the setup, a good default. Adam
              variants adapt per-parameter and can converge faster on short runs.

          

          

            
            
            
Stop early after this many epochs with no val improvement. Set
              it near your epoch count to effectively disable early stopping. Range 0 to 100.

            

          

        


        

          
          

            

              

                

                  
                  
                  
Blank = auto-select: CUDA GPU if available, else mps
                    (Apple silicon GPU), else CPU. Or set a GPU index (0 for the first NVIDIA
                    GPU), mps, or cpu. Training on CPU is very slow.

                

                

                  
                  
                  
Dataloader worker processes. Keep 0 on Windows (the safe
                    default); raise on Linux for faster loading. Range 0 to 16.

                  

                

              

              

                
                
                
Any other ultralytics train argument as key=value pairs.
                  Locked keys (model, imgsz, pretrained, weights, resume) are rejected, and bounded
                  keys keep their bounds here too.
